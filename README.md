## ✨ Sobre este repositório
Este repositório contém apenas a **parte frontend** do projeto Partiu – aplicação web para organização de bagagens e planejamento de viagens.  
O frontend é responsável por toda a interface do usuário, formulários, checklist interativo e exibição de informações de viagem.

## ⚡ Funcionalidades
- Todas as telas do site e suas funcionalidades  
- Criação e visualização de viagens, usuários e itens  
- Checklist interativo de itens de bagagem  
- Interface conectada ao backend via JavaScript

## 🛠 Tecnologias
- HTML  
- CSS  
- JavaScript

**Observação**: como algumas funcionalidades dependem do backend ou de APIs externas, este frontend não funciona 100% sozinho. Para testar todas as funcionalidades, veja o repositório FullStack:
